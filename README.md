# Security AI: Whack-a-Mole Effect in AI Code Repair

This project investigates whether scanner-guided fixes for AI-generated code introduce new vulnerabilities or simply increase code complexity without resolving underlying issues.

## Project Structure
- `docs/`: Literature review, feasibility reports, and model cards.
- `notebooks/`: Experimental notebooks meant for Kaggle execution.
- `src/`: Python source files for code generation, CodeQL analysis, and metric computation.
- `configs/`: Experiment parameters.

See `docs/feasibility_report.md` for current execution blockers and environment constraints.
